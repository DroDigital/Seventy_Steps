Updates and save games

For automatic updates, install Seventy Steps through the free itch.io app and let it keep your game up to date.

If you downloaded the game through your browser, you need to download new versions manually. Close the game, download the latest build for your operating system from this page, extract the complete download, and launch the new copy.

Updating keeps your existing save games. Your progress is stored separately from the game’s installation folder, so you can continue in the same save slot on the same computer and user account. This also applies when switching from a browser-downloaded desktop copy to an itch.io app installation.
