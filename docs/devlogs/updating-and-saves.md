# How to update Seventy Steps and keep your saves

Seventy Steps is receiving updates. Here is how to get the latest build and continue your existing journey.

## Automatic updates with the itch.io app

Install the free [itch.io app](https://itch.io/app), open the [Seventy Steps page](https://digitaldro.itch.io/seventy-steps) inside it, and install the game there. The app keeps games installed through it up to date when it is running and online.

If you previously downloaded the desktop game through your browser, you can install it through the app and continue using the same save slots on the same computer and user account.

## Updating a browser-downloaded copy

Downloads made through the website do **not** update themselves.

1. Close Seventy Steps.
2. Download the latest build for Windows, macOS or Linux from the game page.
3. Extract the complete download into a new folder. On macOS, unpack the new app.
4. Launch the new copy and continue in your existing save slot.

Use the complete new build, including its accompanying files. Once you have checked that the new copy works and your saves appear, you can remove the old game download.

## Your saves stay with you

**Normal updates preserve your existing save games.** Progress is stored in your user data folder, separately from the game’s installation. Keep using the same computer and user account; no manual save transfer is needed to update or to switch to the itch.io app.

If you want to make a separate backup, close the game and copy its `saves` folder:

- **Windows:** `%APPDATA%\Seventy Steps\saves`
- **macOS:** `~/Library/Application Support/Seventy Steps/saves`
- **Linux:** `~/.config/Seventy Steps/saves`, or `$XDG_CONFIG_HOME/Seventy Steps/saves` if you have set a custom configuration location.

Keep this user data folder when updating. These are local saves; moving to another computer requires copying them separately.
