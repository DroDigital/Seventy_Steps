# Baked surface detail

The world texture generator adds seeded, tileable surface detail to all its RGBA textures. Stone and masonry gain fine pores; wood and clapboard gain directional fibers; snow gains pale crystalline facets; cloth gains broad, soft relief; hide gains soft pores; and water gains relief that follows its existing ripples. Cloth's neutral treatment also suits the many mixed-material meshes that share it. Directional shading derived from existing surface values gives the materials an embossed appearance. This lighting is baked into the texture and does not change with the scene's lights. The detail is baked before mipmaps are created, so it adds no texture samples, shader instructions or draw calls at render time. It cannot add real geometric depth or recover detail absent from an asset.

`applySurfaceDetail(pixels, width, height, seed, strength?, profile?)` in `src/render/surfaceDetail.ts` can be reused on another surface's row-major `Uint8Array` of RGBA8 pixels. Profiles are `generic` (the default), `stone`, `wood` (vertical grain), `woodAcross` (horizontal grain), `snow`, `cloth`, `hide`, `water`, and `organic`. The buffer must contain exactly `width * height * 4` bytes and have positive integer dimensions. It is modified in place; alpha is preserved. Most profiles apply a shared gain to each channel, with possible slight hue changes from clipping and rounding; snow facets add a pale cool tint. The default strength is 1, values from 0 to 1 reduce the effect, and 0 disables it. Strength must be finite. Apply it before creating mipmaps. The generated field wraps, but the source texture must itself tile if the result is to tile. Pick a stable seed for repeatable results.

The world texture factory enables the overlay for its generated materials. Cloth also serves as a neutral base for glass, liquid, wax, mirrors, panes, transparent surfaces and self-lit effects; those uses get a separately cached plain cloth texture. Known opaque metal and wax uses select it with `neutralCloth`. Other effects and mixed-material meshes that share enhanced world textures receive their detail as well. `generateTexture(kind, seed, false)` produces the original texture without the overlay. The overlay does not automatically apply to sprites, imported imagery, sky, the separate sea shader, visual effects or other materials that use a separate rendering path; those can opt in at their own asset-generation step where appropriate. It is a colour treatment, so transparent, emissive and special-purpose textures should be reviewed before using it.
