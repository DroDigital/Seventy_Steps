# Plan C: the eight Outer Gods

Merged draft (before the skeptical critic's review, which was still running). Generated by a planning workflow; read as a proposal, not a decision.

- **overview**: MERGED PLAN, EIGHT OUTER GODS. Each god gets a different KIND of incomprehensibility, and each is found by breaking a rule every other boss obeys. 1 AZATHOTH, the body: the court road carries the still and refuses the moving (the same noise() rule the fight uses); the god is a hole in the stars; the map hides and misplaces the Court; the wall is the Other Gods dancing. 2 DAEMON PIPERS, sound as place: a piping with no source that you follow, leaving notes hanging in the air as a score you have walked; the wall is an organ. 3 OTHER GODS, the gaze: the way opens only for one who does not look; shadows dance in the cloud and vanish when stared at; the stones part behind your back. 4 YOG-SOTHOTH, time: the stars come right in the waning hour, a sphere settles beside you wherever you stand, and three passes through the one gate move the night a third each (3 x 360 s = exactly one night, so the clock ends where it began: past, present and future one). 5 'UMR AT-TAWIL, the guide: a veiled figure only you see is always one room ahead; the hall is the room you fell asleep in; the door is a plain wooden one, the dreamer's own. 6 ANCIENT ONES, the mind as key and stopped time: a lattice and a gate that only a clear head sees, the world holds still inside the ring, and you are the missing seventh prism. 7 SHUB-NIGGURATH, lost is found: a breathing wood, a horn-tree maze with no map, Young that creep only when unwatched, and a gate that opens on the exhale. 8 NYARLATHOTEP, he finds you: a handbill at every region boss's fall, a quest lead that lies, a door of cloth in the shrine you trust, then a show; the fight is a three-act performance in masks.
PICKS AND GRAFTS. Azathoth takes set B's drift road and lying map plus set A's dancer wall, hearing ring and beat clock; set A's teleporting loop seam is dropped (riskier; the drift tells the same rule with no teleport). Pipers take set A's lure (a sound followed, hanging notes) plus set B's organ-tower notes; set B's walking file is dropped so the Guide's followed figure stays unique to Umr. Other Gods take set A's avert act plus set B's cloud lid, trilith wall and optional Barzai look-up tier; a Layer.unwatched field is NOT needed. Yog takes set B's descending sphere plus set A's three-pass hour shift. Umr takes set B's guide plus set A's reading room and wooden door; the guide is a set of FIXED stops, never a pathfinder. Ancient Ones take set B's stilled time and double plus set A's minMind lucid layer and lattice. Shub takes set A's maze plus set B's breath, Young and exhale gate, split in two PRs (breath first). Nyarlathotep takes set A's handbills plus set B's door at the shrine; the Exhibition is the door and a cinema scene played in place (no dungeon; a dungeon is a later optional tier); the fight is set A's playhouse plus set B's masks.
ENGINE DECISIONS. One new Step member, Ordeal (rules hush, follow, avert, pass, sit in systems/ordeals/), not five union members. Place Skin plus Living Houses replace pocket regions (rejected: realmMusic.test needs a recorded track per region, about 40 tests iterate REGIONS). Rift-lite (a runtime c.gate entity that is not in worldLayout().gates) replaces layout-level gates. Leash is stops-based. Cut: loop seam, Memory Plates (save bump), Layer.unwatched, a void drop outside the Court (the land is continuous; fog and skin make 'no outside'), the Exhibition dungeon (tier B).
