# Tools and routes

Every command, route and asset pipeline in full, as CLAUDE.md listed them until 2026-11-24 (CLAUDE.md keeps the short
version). Each pipeline writes generated data under `src/data`; run `npm run check` after any of them.

## Running the game

- `npm run dev`: title (it opens out of the dark with its theme on the first key or click, at once where the browser allows sound; New game opens on the intro), then the open world saved to localStorage (click captures the mouse; keys rebindable in Controls; E rests,
  talks and passes a boss's fog (a realm's gate has no key: walk into it, and nearing one says where it leads); R Reagent, T Laudanum, G oil, V reload; M map (click a lit ★ twice: travel; Q/E, the pad's L3 or a name under the heading: another realm with a sign lit, its signs travelled to the same; right-click or F, the pad's Y, sets a marker the minimap points to); Esc/Start: pause, map, journal, arms, settings with their tabs: display, sound, play, accessibility, controls). `?fresh` new game, no title; `?demo` the demo (the university and Arkham, to Keziah Mason); `?arena` combat arena; `?bestiary` every roster entity (click to fight); `?spawn=<id>
  [&variant=eldritch|boss]`; `?look` look test (1–9, drag/wheel/O); `?perf` the frame meter (F3 toggles it anywhere; it also says what the input hears: keys, mouse, the pad); `?bench` the benchmark; `?trailer[&hold=n]` the picture alone, turning about eight places (footage for a trailer); `?debug` debug panel (sliders, H hides) + `window.game`/`world`/`audio`/`life`/`cinema`/`pipeline` (`grab()`: the low-res picture)/`sky`/`scene`/`camera`/`settings`. Cutscenes (wake, a horror's first arrival and fall, endings) skip with Esc/Enter/Space/E; Settings › Play › Cutscenes.
- World editor (round 110, `npm run dev` only, never in a release): F8 in the open world, or `?edit`; hold the right mouse button to fly, click to hold, G/R/S/H move, turn, size, raise; the panel adds props, lights and foes' posts and downloads the edits as one file. `node tools/world_edits.mjs describe|apply <export.json>` turns a posted file into `src/data/worldEdits.ts` (then `npm run check`; docs/WORLD_EDITOR.md).

## Asset pipelines

- `python3 tools/audio_levels.py` (needs `pip install av numpy`): measures every recording in `public/audio` into `src/data/sampleLevels.ts` (run it when one is added or changed); `python3 tools/voice_process.py <take.mp3> <public/voice clip> [--hold START:LEN]` (needs `pip install av numpy scipy`): treats a take of Peaslee's as round 42 left his clips, lower and brisker with its pauses cut (`--hold` keeps one; every other voice goes in as ElevenLabs gives it; docs/VOICES.md); `python3 tools/reviewed_look.py` (needs `pip install pillow numpy`): measures the reviewed creature art for what the renderer adds to it into `src/data/reviewedLook.ts` (where fourteen forms' eyes are, the exact colour of seventeen forms' lit marks and every form's own matter, how wide each boss's painted body is, and a sphere body's ground row; a lathed colossus's hurt zones follow its painted breadth; run it when the pack in `public/creatures/reviewed` changes, then `npm run check`); `python3 tools/add_reviewed_frames.py [--dry] <delivery folder>` (needs `pip install pillow`): adds frames the author drew after the library (the colossi's stoop and its halfway pose, the bosses' left and back attack and hurt) to the packed reviewed art, checked against their manifest; `python3 tools/replace_reviewed_sprite.py [--dry] <key>... <folder>` (or `--all <folder>`): puts creatures the author drew again whole ('Umr at-Tawil, Nyarlathotep, the sixteen of round 56, nine more of round 57, Nug, Yeb and Shub-Niggurath of round 92) in place of their old frames, attack and hurt from the front only (a colossus's stoop frames too, drawn in place), for a scope that grows, shrinks or loses its mirror (run both again, in order, after a `tools/pack_reviewed_assets.py` repack, which does not know them; docs/CREATURE_ART.md); `python3 tools/boss_music.py` (needs `pip install av numpy`): reads every boss theme in `public/music/bosses` into `src/data/bossMusicMap.ts` (its tempo and bar grid, entry, loop, hot stretch and gain; run it when a theme is added or changed, then `npm run check`).
- `python3 tools/sprite_review.py fetch|audit|sheets|fix` (needs `pip install pillow numpy`): reviews the creature sprite library's walks (two-frame profile walks, facing, ground line, jitter, off-model frames) into `docs/SPRITE_REVIEW.md`, draws contact sheets and makes the mends that need no drawing; the brief and how to run it: docs/SPRITE_QA.md; `python3 tools/sprites/walk4.py <pack>`: four-frame side walks for the two-legged creatures it can read, a passing pose made from each contact's pixels. `python3 tools/sprites/fromsheet.py <sheet> <pack> <key> <side>`: four walk frames from an image model's 2x2 sheet on magenta, set by their own feet and torso and snapped to the creature's palette (`--frames` names what each cell becomes, `--flip-cells` mirrors each cell); `tools/sprites/ground.py <pack>`: every grounded creature on the brief's ground line; `tools/sprites/legswap.py <pack> <key> <side>`: a walk's second half from its first, the legs' shades exchanged (`--mirror-legs`: a crawler's legs mirrored about their hips); `tools/sprites/v1fixes.py <pack>`: once, the library's v1 defects that need no drawing (Innsmouth's swapped sides, Cthulhu's views, the Colossus's right, the gallery's load error and banner); `tools/sprites/deliver.py`: the one zip of every creature folder that changed, whole, plus the gallery page (`--theirs-from`: the author's own frames for the sides they drew) (docs/SPRITE_QA.md, docs/SPRITE_HANDOFF.md). `python3 tools/sprites/prompts.py md|refs`: the ChatGPT prompt for each of the library's 105 entries (`docs/SPRITE_PROMPTS.md`) and their references; `python3 tools/sprites/batches.py <v1 pack> <out>`: the ChatGPT batches (ten sheets a request) for every two- and four-legged creature's front, back and side walks, with references (`docs/SPRITE_BATCHES.md`).
- `python3 tools/models/bake_models.py <folder holding the unpacked Kenney kits>` (needs `pip install pillow numpy`): bakes the CC0 models the arenas stand (`MODELS` in the tool: a kit, a file, whether round, the metres it is fitted to) into `src/data/models/index.ts` (their boxes), `pack.ts` (their faces: flattened, welded, 16-bit points, the colour of the face) and `CREDITS.md`; run it when the list changes, then `npm run check` (`tests/arenaSets.test.ts` keeps every baked model stood by some arena). `?debug` and a browser capture show an arena as the player does: `window.world.update(x, z, 300000)` builds all about a point at once.
- `python3 -I tools/marks/bake_marks.py <the Kenney Particle Pack's 'PNG (Transparent)' folder> [src/data/markAtlas.ts] [--preview sheet.png]` (needs `pip install pillow numpy`; round 90): the two masks of the mark atlas that `render/particles.ts`'s `mark` and `trace` shapes draw (a blot, and a smear frayed by the mottle of the pack's `smoke_05`, both made in the baker; seeded, so a rerun is byte for byte the same); run it if the list or a mask changes, then `npm run check`.
- `python3 -I tools/models/bake_boss_models.py <work dir> [--only id,id] [--sheet out.png]` (needs `pip install bpy numpy pillow`; round 71): bakes the supplied asset packs' models the boss places stand (`tools/models/boss/`: `unpack.py` unpacks the packs into the work dir, `manifest*.py` says which object of which pack becomes which model, its class, fit, solids and flame anchors, `proc*.py` the forms built in code) into `src/data/models/bossIndex.ts` + `bossPack.ts`, beside the Kenney set's, which it leaves; run it with no `--only` to remake all 267 (round 72: packs 19 to 29 added and 10, 11 and 14 gone, eight of the new ones CC BY 4.0 and credited with their changes; round 75: thirteen more forms made in code, `proc_rites.py` + `manifest_rites.py`, and nine more pieces of the alien pack, `manifest_p20.py`; round 79: packs 30 to 54 added but 41 (PSX Shelves: its licence forbids redistributing its assets; the Library's shelves are built, `render/setShapesBooks`) and the Poly Haven compressor, the dungeons' models, `docs/DUNGEON_MODELS.md`; `drop_alpha` leaves out a glass's clear faces, `glass_alpha` keeps them as glass, `plane` makes a flat panel a mirror and `fill` builds a liquid under a vessel's glass, `tools/models/boss/fill.py`: four classes beside the old, glass 12, liquid 13, mirror 14, wax 15); pack 07 (a licence that forbids its raw assets being shipped) is not in a manifest and `tests/bossPlaces.test.ts` keeps it out; then `npm run check`. Round 76: the same tool bakes the gates' set (`manifest_gates.py`, `set: 'gate'` into `src/data/models/gateIndex.ts` + `gatePack.ts`; `python3 -I tools/models/gates/fetch.py <work dir>` fetches the free sources first, docs/GATES.md; the three Sketchfab models, CC BY 4.0, are downloaded by hand into `<work dir>/w20`, `/w21` and `/w22`; a manifest's `join` makes one object of the pieces a viewer split, `cap` closes a `cut`). `python3 -I tools/flames/bake_flames.py <folder with fire_3.gif> src/data/flameAtlas.ts` (needs `pip install pillow numpy`; round 79): the pixel flames' flipbook that `render/flames.ts` draws at every fire, torch and lamp (the free 'Fire' of ZomBCool, CC0); `python3 -I tools/psx/bake_psx_textures.py <the PSX Dungeon's Textures folder> src/data/psxDetail.ts`: the PS1 patterns `render/textures.ts` lays over stone, flagstones and planks. `node tools/boss_shots.mjs <out> [--views approach,gate,fight,high,wall,p:a:c:h:ta:tc:th] [--info stats.jsonl] [boss ...]` (needs Playwright and `npm run dev`): photographs the open horrors' places from the game (docs/BOSS_PLACES.md) and, with `--info`, counts the frame's draws and triangles.
- `python3 -I tools/player/animate.py [--module m] [--only id] [--check]` then `python3 -I tools/player/clipbake.py` (round 81; needs `pip install bpy numpy scipy pillow`, Python 3.13, `libegl1 libgl1-mesa-dri` for the previews; `bpy` is for these tools only, not a dependency of the game): the investigator is modelled and animated in Blender from code (`tools/player/`, docs/PLAYER.md): `export_data.mjs` the game's numbers, `build_blend.py` the model and rig (`build/investigator.blend`, gitignored: regenerated), `clips/*.py` each move's key poses (the DSL is `clipkit.py`; the first model is `clips/cane.py`), `animate.py` solves them into Blender Actions and reads them back (`--check`), `bake_player.py` the model's parts into `src/data/player/playerPack.ts` + `playerIndex.ts`, `clipbake.py` the Actions into `playerClips.ts` (a quaternion for every joint on every 60 Hz frame of a move: the game still has no skeleton). While keying, `python3 -I tools/player/check.py <clip id> --module <m>` (no Blender: QA lines and a stick-figure sheet) and `tools/player/preview.py turnaround|sheet` (the modelled figure) show it; `PLAYWRIGHT_MODULE=… node tools/player_shots.mjs <out> turn|npcs|clip <move[,move]>|gait` photographs it in the running game (`npm run dev`, `?arena&debug`).
- `node tools/itch_art.mjs frames [boss ...]` then `pack --hero <png> [<png> ...]` (the same needs): the itch.io page's screenshots (fights, no sanity distortion), cover, social image, wide cover, logo and profile picture into `store/itch/` (docs/RELEASE.md).
- `node tools/store_shots.mjs [url] [first..last]` (needs Playwright, and `npm run dev` running): the store's stills and capsules into `store/` (docs/PRESS_KIT.md).

## Building, testing and shipping

- `npm run check`: typecheck + the everyday Vitest set. Must pass before every commit. `npm run audit`: the slow tests (the soak, the bots that fight every creature, the walks of every dungeon and prop, a body walked at every house from eight sides, `tests/balance.test.ts` → `docs/BALANCE.md` with `BALANCE_WRITE=1`); run it when a boss, a creature or the world changes. The finite-resource NG+ benchmark is `tests/ngPlus.test.ts`; `NGPLUS_WRITE=1 npm run audit` refreshes `docs/NGPLUS_RESULTS.md` (see `docs/NGPLUS.md`). `npm run check:all`: both (what CI runs).
- `npm run build`: typecheck + production build into `dist/`. `npm run build:demo`, `npm run check:demo`, `npm run smoke:demo`: the demo as a build of its own (`vite build --mode demo`): `__DEMO__` is true in it alone, the rest of the game is pruned out of its bundle and left out of its dist, and the leak check reads what it holds (docs/DEMO_BUILD.md).
- `npm run package` (`:win`, `:linux`, `:mac`): build, make the icon, then pack the shell for Steam into `release/` (electron-builder, unpacked: a depot; pack each platform on that platform; `:mac` makes an Apple Silicon and an Intel app, `-- --universal` merges them: `tools/package_mac.mjs`; docs/STEAM.md, docs/RELEASE.md). `npm run smoke`: starts the packed game with `--smoke-test` and fails unless it reaches its title (`tools/smoke_packaged.mjs`, `--arch x86_64` for an Intel app under Rosetta, `--timeout`, `--verbose`; CI does it on each platform: `.github/workflows/release-builds.yml`). `npm run steam:upload`: writes the SteamPipe scripts (`--run`: sends them; `tools/steam_upload.mjs`). itch.io: a build packed with `-c.extraMetadata.channel=itch` keeps off Steam (`package_mac.mjs --channel itch`); `npm run itch:push` shows what it would push with butler (`--run` sends it; `tools/itch_push.mjs`), or tick *itch* when running the release workflow (docs/RELEASE.md).
- `npm run desktop`: build, then open it in the desktop shell (Electron: what ships on Steam; sound from boot, so the title opens straight into its menu with its theme; F11 or Alt+Enter: fullscreen). `npm run desktop:dev`: the shell on the running dev server. `npm run icon`: the icons (drawn in code: the Elder Sign) to `build/`: `icon.png`, `icon-mac.png` (set in, with a shadow) and `avatar.png` (a store's profile picture).
