# Finite-resource journey benchmark

Generated by NGPLUS_WRITE=1 npm run audit. Two deterministic seeds/starts, skill 0.9, cane +5, gun +5, ten healing doses, real health, finite ammunition, real death; no waived mechanics. The reference build has 18/9/17 attributes; the cap build has 30/30/30. Both are measured at NG+7. The clear synthetic arena uses the authored encounter radius; this is not a collision or human playtest of the actual dungeon.

Failures remain visible. A fixed bot is a regression benchmark, not a success-rate prediction for players or proof that every encounter is fair. Some losses are to unsupported strategies, including petrification/platform navigation, or the four-minute timeout. Successful-run medians exclude deaths and timeouts. Acceptance floors are roster regressions (45%, 45%, 35%, 25%), not individual fight certifications.
