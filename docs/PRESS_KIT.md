# Press kit

## The game in a line

*Seventy Steps*: a Lovecraftian open-world soulslike in retro 3D, in which sanity is a second health bar and the world answers it.

## Look and sound

Billboarded sprites in low-poly worlds, a low-resolution picture graded by realm, dithered and fogged; a lantern and a moon for light
at night; menus of drifting mist. Every texture, sprite and mesh is generated by code. The score is made with Suno, the voices are
synthetic (ElevenLabs), the sound effects CC0 recordings: disclosed on the store page ([`STORE_PAGE.md`](STORE_PAGE.md)).

## Pictures and a trailer

- **Stills and capsules, from the game itself:** with the dev server running (`npm run dev`), `node tools/store_shots.mjs` (it needs
  Playwright with a Chromium: see its header) writes `store/shots/` (1920 × 1080 stills of eight places) and `store/capsules/`
  (header, small, main, vertical, library and page background, the wordmark over a still). Run it on a real GPU for the final pictures:
  the first set was made with a software renderer, which is slow and flat.
- **The trailer's footage:** open the game with `?trailer` (the picture alone, no HUD, no hints, the camera turning about eight of the
  dream's places, each held for 14 seconds, for ever), and record it with OBS or the Steam recorder; `?trailer&hold=3` stays at the
  fourth place. Photo mode (P) keeps a picture of any moment as a PNG.
- **Logo:** the wordmark is drawn by code (`src/ui/logoArt.ts`); `store_shots.mjs` is where it is put over a picture. A separate
  transparent logo is not made yet.
