# CLAUDE.md

Lovecraftian open-world soulslike in retro 3D. **Spec: `docs/SPEC.md`.** At session start read it and this
file, then do only the phase named in the message. Log judgment calls in `docs/DECISIONS.md`.

## Commands
- `npm run dev`: title (it opens out of the dark with its theme on the first key or click, at once where the browser allows sound; New game opens on the intro), then the open world saved to localStorage (click captures the mouse; keys rebindable in Controls; E rests,
  talks and passes a boss's fog (a realm's gate has no key: walk into it, and nearing one says where it leads); R Reagent, T Laudanum, G oil, V reload; M map (click a lit ★ twice: travel; right-click or F, the pad's Y, sets a marker the minimap points to); Esc/Start: pause, map, journal, arms, settings with their tabs: display, sound, play, controls). `?fresh` new game, no title; `?demo` the demo (the university and Arkham, to Keziah Mason); `?arena` combat arena; `?bestiary` every roster entity (click to fight); `?spawn=<id>
  [&variant=eldritch|boss]`; `?look` look test (1–9, drag/wheel/O); `?perf` the frame meter (F3 toggles it anywhere; it also says what the input hears: keys, mouse, the pad); `?bench` the benchmark; `?trailer[&hold=n]` the picture alone, turning about eight places (footage for a trailer); `?debug` debug panel (sliders, H hides) + `window.game`/`world`/`audio`/`life`/`cinema`/`pipeline` (`grab()`: the low-res picture)/`sky`/`scene`/`camera`/`settings`. Cutscenes (wake, a horror's first arrival and fall, endings) skip with Esc/Enter/Space/E; Settings › Play › Cutscenes.
- `npm run check`: typecheck + the everyday Vitest set. Must pass before every commit. `npm run audit`: the slow tests (the soak, the bots that fight every creature, the walks of every dungeon and prop, a body walked at every house from eight sides, `tests/balance.test.ts` → `docs/BALANCE.md` with `BALANCE_WRITE=1`); run it when a boss, a creature or the world changes. `npm run check:all`: both (what CI runs).
- `python3 tools/audio_levels.py` (needs `pip install av numpy`): measures every recording in `public/audio` into `src/data/sampleLevels.ts` (run it when one is added or changed); `python3 tools/voice_process.py <take.mp3> <public/voice clip> [--hold START:LEN]` (needs `pip install av numpy scipy`): treats a take of Peaslee's as round 42 left his clips, lower and brisker with its pauses cut (`--hold` keeps one; every other voice goes in as ElevenLabs gives it; docs/VOICES.md); `python3 tools/reviewed_look.py` (needs `pip install pillow numpy`): measures the reviewed creature art for what the renderer adds to it into `src/data/reviewedLook.ts` (where ten forms' eyes are, how wide each boss's painted body is, and a sphere body's ground row; a lathed colossus's hurt zones follow its painted breadth; run it when the pack in `public/creatures/reviewed` changes, then `npm run check`); `python3 tools/add_reviewed_frames.py [--dry] <delivery folder>` (needs `pip install pillow`): adds frames the author drew after the library (the colossi's stoop and its halfway pose, the bosses' left and back attack and hurt) to the packed reviewed art, checked against their manifest; `python3 tools/replace_reviewed_sprite.py [--dry] <key>... <folder>` (or `--all <folder>`): puts creatures the author drew again whole ('Umr at-Tawil, Nyarlathotep, the sixteen of round 56, nine more of round 57) in place of their old frames, attack and hurt from the front only, for a scope that grows, shrinks or loses its mirror (run both again, in order, after a `tools/pack_reviewed_assets.py` repack, which does not know them; docs/CREATURE_ART.md); `python3 tools/boss_music.py` (needs `pip install av numpy`): reads every boss theme in `public/music/bosses` into `src/data/bossMusicMap.ts` (its tempo and bar grid, entry, loop, hot stretch and gain; run it when a theme is added or changed, then `npm run check`).
- `python3 tools/sprite_review.py fetch|audit|sheets|fix` (needs `pip install pillow numpy`): reviews the creature sprite library's walks (two-frame profile walks, facing, ground line, jitter, off-model frames) into `docs/SPRITE_REVIEW.md`, draws contact sheets and makes the mends that need no drawing; the brief and how to run it: docs/SPRITE_QA.md; `python3 tools/sprites/walk4.py <pack>`: four-frame side walks for the two-legged creatures it can read, a passing pose made from each contact's pixels. `python3 tools/sprites/fromsheet.py <sheet> <pack> <key> <side>`: four walk frames from an image model's 2x2 sheet on magenta, set by their own feet and torso and snapped to the creature's palette (`--frames` names what each cell becomes, `--flip-cells` mirrors each cell); `tools/sprites/ground.py <pack>`: every grounded creature on the brief's ground line; `tools/sprites/legswap.py <pack> <key> <side>`: a walk's second half from its first, the legs' shades exchanged (`--mirror-legs`: a crawler's legs mirrored about their hips); `tools/sprites/v1fixes.py <pack>`: once, the library's v1 defects that need no drawing (Innsmouth's swapped sides, Cthulhu's views, the Colossus's right, the gallery's load error and banner); `tools/sprites/deliver.py`: the one zip of every creature folder that changed, whole, plus the gallery page (`--theirs-from`: the author's own frames for the sides they drew) (docs/SPRITE_QA.md, docs/SPRITE_HANDOFF.md). `python3 tools/sprites/prompts.py md|refs`: the ChatGPT prompt for each of the library's 105 entries (`docs/SPRITE_PROMPTS.md`) and their references; `python3 tools/sprites/batches.py <v1 pack> <out>`: the ChatGPT batches (ten sheets a request) for every two- and four-legged creature's front, back and side walks, with references (`docs/SPRITE_BATCHES.md`).
- `python3 tools/models/bake_models.py <folder holding the unpacked Kenney kits>` (needs `pip install pillow numpy`): bakes the CC0 models the arenas stand (`MODELS` in the tool: a kit, a file, whether round, the metres it is fitted to) into `src/data/models/index.ts` (their boxes), `pack.ts` (their faces: flattened, welded, 16-bit points, the colour of the face) and `CREDITS.md`; run it when the list changes, then `npm run check` (`tests/arenaSets.test.ts` keeps every baked model stood by some arena). `?debug` and a browser capture show an arena as the player does: `window.world.update(x, z, 300000)` builds all about a point at once.
- `node tools/itch_art.mjs frames [boss ...]` then `pack --hero <png> [<png> ...]` (the same needs): the itch.io page's screenshots (fights, no sanity distortion), cover, social image, wide cover, logo and profile picture into `store/itch/` (docs/RELEASE.md).
- `node tools/store_shots.mjs [url] [first..last]` (needs Playwright, and `npm run dev` running): the store's stills and capsules into `store/` (docs/PRESS_KIT.md).
- `npm run build`: typecheck + production build into `dist/`.
- `npm run package` (`:win`, `:linux`, `:mac`): build, make the icon, then pack the shell for Steam into `release/` (electron-builder, unpacked: a depot; pack each platform on that platform; `:mac` makes an Apple Silicon and an Intel app, `-- --universal` merges them: `tools/package_mac.mjs`; docs/STEAM.md, docs/RELEASE.md). `npm run smoke`: starts the packed game with `--smoke-test` and fails unless it reaches its title (`tools/smoke_packaged.mjs`, `--arch x86_64` for an Intel app under Rosetta, `--timeout`, `--verbose`; CI does it on each platform: `.github/workflows/release-builds.yml`). `npm run steam:upload`: writes the SteamPipe scripts (`--run`: sends them; `tools/steam_upload.mjs`). itch.io: a build packed with `-c.extraMetadata.channel=itch` keeps off Steam (`package_mac.mjs --channel itch`); `npm run itch:push` shows what it would push with butler (`--run` sends it; `tools/itch_push.mjs`), or tick *itch* when running the release workflow (docs/RELEASE.md).
- `npm run desktop`: build, then open it in the desktop shell (Electron: what ships on Steam; sound from boot, so the title opens straight into its menu with its theme; F11 or Alt+Enter: fullscreen). `npm run desktop:dev`: the shell on the running dev server. `npm run icon`: the icons (drawn in code: the Elder Sign) to `build/`: `icon.png`, `icon-mac.png` (set in, with a shadow) and `avatar.png` (a store's profile picture).

## Rules (spec §0, condensed)
- Do only the requested phase; never scaffold later ones. Plan in ≤15 lines, then execute without asking.
- Ambiguity: pick the simplest option that fits the spec, log one line in `docs/DECISIONS.md`, keep going.
- No file dumps or large diffs in chat. End each phase with a ≤10-line summary and a git commit.
- Surgical edits. Files under 300 lines with one responsibility each.
- Verify with `npm run check` and read only the failing output. Never open `node_modules/` or `dist/`.
- No asset files: textures, sprites, meshes and audio are generated in code. Exceptions: the arenas' models (round 61, asked for: `src/data/models`, a few score CC0 pieces (fifty-nine since round 62) of Kenney's kits baked by `tools/models/bake_models.py` into compact data, never loaded as files and credited in `src/data/models/CREDITS.md`; every other piece of an arena's set is built in code), the title theme (`public/music`), the realms' background music (`public/music/realms`: fifteen tracks made with Suno, `public/music/CREDITS.md`), the boss themes (`public/music/bosses`: forty-eight themes made with Suno, untouched MP3s, also in `public/music/CREDITS.md`), the recorded sounds (`public/audio`: CC0 recordings cut and treated for the game, each credited in its `CREDITS.md`; playtest round 6) and the voices (`public/voice`: one recording of each line the people and the horrors say, made with ElevenLabs' Eleven v4 from `data/speech*.ts`, `docs/VOICES.md`).
- Creatures are data, not classes (15–30 lines each); boss phase scripts are data too.
- Deps: `three` (+ `@types/three`), `typescript`, `vite`, `vitest`, `electron` (the desktop shell, playtest round 11), `gamepad-node` (the shell's controllers over SDL2, round 36), `steamworks.js` (the shell's Steam: achievements, overlay; round 47), `electron-builder` (packaging, round 47). Ask before adding anything else.
- Simulation code (combat, stamina, sanity, AI, registry, streaming math) must not import Three.js.
- Out of scope: multiplayer, skeletal animation, imported models/textures (but for the arenas' baked CC0 models, above), mobile.

## Conventions
- Sim: fixed system order in `stepGame`; moves are 60 Hz frame windows `[from, to)`; yaw 0 faces +z, right = (−cos, sin).
- Colours are display sRGB end to end (`ColorManagement` off); every material is a `ShaderMaterial`.
- World materials share one uniform set (`worldUniforms`). FX flow: `FxState → computeFx() → update*Uniforms()`.
- Sanity FX are `[calm, mad]` ramps in `tuning.ts`, blended by stress = min(1 − sanity/100, fx cap); hooks listen to `SanityBandChanged`/`InsightChanged`.
- New creature: its id in `roster.ts` + an entry in its tier file (a `voice`, or its tier's); `npm run check` runs `validateRegistry()`.
- New realm: its look in `data/looks.ts` (its grade, accents, mist, sky, light and far colours); `npm run check` makes no two realms grade alike and keeps every colour that lights or fills the scene from reading as an anomaly hue.
